# 新项目 · 网页分享版

一群企鹅，一个新项目。通过公司里的交流、试玩和选择，走向不同的未来。

此仓库只包含可公开运行的静态发行文件，使用 GitHub Pages 部署。入口为 index.html。
建议使用桌面浏览器：WASD 移动，点击场景后鼠标观察，E 互动，空格继续对白，Esc 暂停。
影片按需加载，带原生声音；浏览器要求点击播放时，请点击画面里的按钮。
存档保存在此网站的浏览器本地存储，清除网站数据会删除存档。

网页运行层使用 WebGL2 / Three.js，复用 Godot 工程的场景、模型、骨骼动画、剧情和音视频。
本版没有桌面 MagicGI。Three.js 为 MIT，许可证见 THREE_LICENSE.txt。
